# Faraz Chishty Portfolio

Engineering and robotics project portfolio.

## How to use

1. Replace the project titles and descriptions in `index.html`.
2. Add project photos to the `images` folder.
3. Add your Akira font file to the `fonts` folder with this exact name:

`Akira Expanded Demo.otf`

4. Commit and push to GitHub.
5. Publish with GitHub Pages.
